# Salon TV : page téléphone

Page statique utilisée pour le jumelage par QR code de l'app Salon TV, un lecteur IPTV pour TV LG.

Elle chiffre dans le navigateur la liste saisie sur le téléphone, puis dépose le message chiffré sur un relais ntfy : seule la TV qui affiche le QR code peut le lire. La page n'inclut aucun traceur et ne stocke rien.

Ce dépôt ne contient que la page (`index.html` et `pair.js`). Elle ne fonctionne qu'avec le QR code d'une TV.
